## 📂 Мои проекты

### 📚 Проект "Библиотека" (Block 8)
Консольное приложение для управления книгами, демонстрирующее принципы ООП.
- **Классы:** `Book` (книга), `Library` (библиотека), `Employee` (сотрудник), `Student` (студент).
- **Применённые технологии и концепции:**
  - Инкапсуляция и свойства (`get`, `set`, `private set`).
  - Модификаторы доступа (`public`, `private`, `readonly`, `const`).
  - Статические члены (счётчики созданных объектов).
  - Переопределение методов `object`: `Equals`, `GetHashCode`, `ToString`.
  - Работа с `record` и оператором `with` (для `BookDto`, `StudentDto`).
  - Обработка исключений (`try-catch`).
  - Работа с коллекциями (`List<T>`, `params`).
  - Использование `enum` (`Genre`).
